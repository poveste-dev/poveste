# Examples

These pages show story patterns in Vue and Svelte, Tailwind's generated stories, and two visual-regression setups. A runnable book for every supported framework, Vue, Nuxt, Svelte, SvelteKit, Quasar, Solid and React, is in the [repository's `examples` directory](https://github.com/poveste-dev/poveste/tree/main/examples).
