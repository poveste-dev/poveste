# NOTICE

**poveste** is a fork of [**histoire**](https://github.com/histoire-dev/histoire),
a Vite-powered story/component-workbook tool originally created by
**Guillaume Chau** ([@Akryum](https://github.com/Akryum)) and contributors.

histoire is MIT-licensed. This fork preserves the original copyright and license
(see [`LICENSE`](./LICENSE)) and continues the project's development under a new
name, `poveste` (Romanian for "story"), maintained by Sorin Gitlan
([@50rayn](https://github.com/50rayn)).

## Relationship to histoire

- poveste aims to be a **drop-in fork**: existing histoire projects should be
  able to migrate by changing dependencies, with the `<Story>` / `<Variant>` API,
  the `.story.*` file convention, and the `histoire.config.*` file continuing to
  work.
- This is an **independent, community-maintained fork**, not endorsed by or
  affiliated with the original authors unless stated otherwise.
- Gratitude to Guillaume Chau and every histoire contributor for the original work.
