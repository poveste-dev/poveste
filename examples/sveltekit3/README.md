# SvelteKit 3 example

A fixture: a SvelteKit 3 project, as `sv create` scaffolds it, with a Poveste book. It proves the Kit 3 range of `@poveste/plugin-svelte` in dev, build and preview, and with `svelte-check` (#1200). `examples/sveltekit` stays on Kit 2 for the floor; #1205 promotes this one to a conformance book.

```sh
pnpm run story:dev
pnpm run story:build && pnpm run story:preview
```
